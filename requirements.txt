# v1.57.3 [2026-05-15] — All version pins removed. uv now resolves the latest
#   Python 3.13-compatible release of each package. The previous pins were a
#   `pip freeze` captured on a Python 3.10/3.11 environment; many predated

#   3.13. Bumping to current versions gets prebuilt cp313 wheels across the
#   board. Once the stack is verified working, re-freeze for reproducibility:
#       uv pip freeze > requirements.lock.txt
#   Resolver settings (index-strategy) live in pyproject.toml [tool.uv].
#
# CUDA torch: the extra-index-url above is PyTorch's CUDA 12.8 wheel index.
#   PyPI's Windows torch wheels are CPU-only (+cpu); the CUDA builds (+cu128)
#   only exist on download.pytorch.org. The old index was cu121, which has no
#   cp313 / no torch >2.5 — that's why a CPU build was getting pulled. RTX 2060
#   + driver 596.21 supports CUDA 13.2, so cu128 is well within range.
#   (Removed a dead onnxruntime-cuda extra-index-url — onnx was a leftover.)
